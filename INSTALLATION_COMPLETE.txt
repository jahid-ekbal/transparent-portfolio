🎨 QUICK CUSTOMIZATION STEPS:

1. UPDATE PERSONAL INFORMATION
   File: index.html
   - Hero section text (line ~70)
   - About biography (line ~130)
   - Contact email (line ~320)
   - Footer info (line ~360)

2. CHANGE COLORS
   File: style.css (lines 29-40)
   Or: tailwind.config.js
   
   Main colors:
   - Primary: #06b6d4 (Cyan)
   - Secondary: #3b82f6 (Blue)
   - Accent: #9333ea (Purple)

3. MODIFY ANIMATIONS
   File: script.js
   - Typing speed (line ~95)
   - GSAP timings (lines ~200-250)
   - Animation delays (lines ~180-195)

4. UPDATE SOCIAL LINKS
   File: index.html
   - GitHub URL (line ~45)
   - LinkedIn URL (footer area)
   - Twitter/Other profiles

5. CUSTOMIZE FORM ACTION
   File: index.html, Contact Form
   - Add FormSubmit.co endpoint
   - Or connect to backend
   - Or use Netlify forms
